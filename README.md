# Orton Heritage website

Static website for Orton Heritage, designed for GitHub Pages.

## Structure
- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `contact.html` — Contact
- `css/style.css` — Shared styles
- `assets/main.js` — Navigation, reveal animation and form preview handling

## Before launch
1. Confirm the public contact email. `hello@ortonheritage.com` is currently shown as the proposed address.
2. Create a Formspree form and replace `YOUR_FORM_ID` in `contact.html`.
3. Make the repository public if using GitHub Pages on a GitHub Free account.
4. Enable GitHub Pages from the `main` branch and root folder.
5. Migrate photography into the repository rather than relying on temporary Wix CDN URLs.
6. Connect `ortonheritage.com` only after the GitHub Pages preview has been checked.
7. Preserve existing Google Workspace MX records when changing DNS.

The site intentionally has no Projects page at this stage. The structure can accommodate one later.
